## Benchmark Modalities

**Modality Types:** text

**Description:** Evaluates text-based agents executing multi-step search queries, browsing web text, and producing textual list-based answers.

## Analytical Tasks

**Task Types:** open ended qa, information extraction, retrieval and ranking, logical and quantitative reasoning, causal and temporal reasoning, calibration and uncertainty, agentic tool use

**Detailed Description:** Requires multi-step agentic search ('agentic_tool_use'), retrieving and filtering information across multiple web pages ('retrieval_and_ranking'), extracting specific entities to build lists ('information_extraction'), resolving complex constraints such as chronological overlaps and quantitative thresholds ('logical_and_quantitative_reasoning', 'causal_and_temporal_reasoning'), generating exhaustive set lists ('open_ended_qa'), and making decisions on when to stop searching under epistemic uncertainty ('calibration_and_uncertainty').

## Summary

DeepSearchQA introduces a 900-prompt benchmark designed to evaluate autonomous web agents on their ability to perform exhaustive, multi-step information-seeking tasks across 17 fields. It shifts the evaluation paradigm from single-answer retrieval to comprehensive, set-based answer generation, addressing the 'Comprehensiveness Gap' in current models.

## Key Findings

Gemini Deep Research Agent and GPT-5 Pro High Reasoning achieved the highest performance (F1 of 81.90% and 78.98% respectively), showing that recursive agentic loops outperform standalone reasoning models. However, a 'Last Mile Problem' persists, with a 13-15 point gap between F1-scores and strict 'Fully Correct' accuracy, driven by failures in dynamic stopping criteria and entity deduplication.

**Plurality Treatment:** noise

**Facets Explanation:** The reference answers were curated by expert data annotators from various sources to reflect realistic user queries. Because the benchmark is based on open-web research tasks, answering requires retrieving external information not provided in the prompt stimulus. The ground truth incorporates both single answers and structured answer sets containing multiple expected items. Any divergence between annotators was addressed in a three-phase validation process where discrepancies were resolved and ambiguous prompts were filtered out, treating disagreement as noise.
