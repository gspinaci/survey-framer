## Benchmark Modalities

**Modality Types:** text

**Description:** Evaluates using text-only bibliographic metadata consisting of record titles and abstracts in English and German.

## Analytical Tasks

**Task Types:** classification, retrieval and ranking

**Detailed Description:** Extreme multi-label text classification (XMTC) and semantic retrieval where models must output a ranked top-k set of relevant standardized terms from a large-scale controlled vocabulary taxonomy (GND).

## Summary

This paper introduces SemEval-2025 Task 5: LLMs4Subjects, a shared benchmark evaluating large language models for automated bilingual subject tagging of scientific and technical library records using the GND taxonomy. It evaluates participating systems using standard retrieval-based metrics and direct, qualitative evaluations conducted by specialized subject librarians.

## Key Findings

Top-performing systems quantitatively combined traditional extreme multi-label classification tools with LLM-assisted translation, synthetic data generation, or cross-lingual embeddings. In qualitative evaluations by human experts, a zero-shot/few-shot prompted LLM ensemble (DNB-AI-Project) outperformed fine-tuned systems, demonstrating the strong generalization capabilities of LLMs in highly technical categorization tasks.

**Facets Explanation:** The reference subject annotations were extracted directly from existing TIBKAT catalog metadata, which are assigned by specialized library subject specialists using the external German National Library's GND taxonomy. Correctly identifying these controlled vocabulary terms requires knowledge of this classification system and its conceptual linkages, which are external to the provided title and abstract stimulus. The paper evaluates performance against a set of multiple pre-existing subject tags per item using precision and recall at k, and it does not address potential annotator divergence in the creation of the catalog metadata.
