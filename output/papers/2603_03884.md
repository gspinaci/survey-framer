## Summary

This paper presents CzechTopic, a human-annotated benchmark for zero-shot topic localization in OCR-processed historical Czech archival documents. The benchmark evaluates models at both the document level (presence detection) and the word level (fine-grained span localization) using an evaluation framework grounded in human inter-annotator agreement.

## Key Findings

The best-performing LLM (GPT-5-2) achieved a word-level F1 of 61.1, which remains significantly below the human agreement baseline of 68.7, indicating precise span localization is a major challenge for current models. Specialized BERT-based models fine-tuned on distilled data (e.g., RobeCzech) achieved highly competitive performance, outperforming several open-source LLMs.
