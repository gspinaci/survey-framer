## Benchmark Modalities

**Modality Types:** text, image

**Description:** The corpus consists of scanned and digital PDFs containing text, complex nested tables, and visual elements (figures, charts, and line graphs) that models must interpret.

## Analytical Tasks

**Task Types:** open ended qa, information extraction, retrieval and ranking, logical and quantitative reasoning, causal and temporal reasoning, visual reasoning, agentic tool use

**Detailed Description:** Tasks require multi-document retrieval across a large 100-year corpus, data extraction from highly complex hierarchical tables, longitudinal reconciliation of revised historical statistics over time (temporal reasoning), multi-step mathematical analysis (e.g., linear regression, inflation adjustments), reasoning over visual trend lines in charts, and autonomous coordination of these actions using tools like Python REPLs and file search APIs.

## Summary

OfficeQA Pro is a grounded reasoning benchmark designed to evaluate AI agents on multi-document analysis over a 100-year corpus of U.S. Treasury Bulletins. It features 133 quantitative questions that require agents to parse complex tables, retrieve historical statistics, and perform multi-step mathematical synthesis. The paper demonstrates that document parsing quality is a significant bottleneck and that current frontier agents struggle to surpass 50% accuracy on the raw PDF corpus.

## Key Findings

Direct LLM baselines fail completely on parametric knowledge (<5% accuracy). The strongest frontier agent (Claude Opus 4.6) achieves 48.1% accuracy on the full raw PDF corpus. Supplying documents pre-parsed by Databricks' ai_parse_document provides a 16.1% relative performance gain across agents and significantly reduces latency and cost.

**Facets Explanation:** The reference answers were created primarily by hired annotators from partners SuperAnnotate and Turing, who generated questions grounded in the Treasury Bulletins starting from a seed set written by the authors. Disagreements during verification or conflicting AI predictions were treated as noise and systematically resolved by a third reviewer or by revising the question to remove ambiguity. Each question maps to a single, deterministic correct answer.
